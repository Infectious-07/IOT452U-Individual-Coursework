# Digital ID Platform

A console based backend that lets a central authority manage Digital IDs while authorised consumer organisations verify them through dedicated portals.

This project is being built for the IOT452U Individual Coursework. Implementation is in Python 3.14 with the standard library only and a small set of dev dependencies for linting and testing.
